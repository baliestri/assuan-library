# Ownership and security boundaries

Assuan is a byte protocol. SecretBuffer and the channel's line buffers use pinned managed arrays, so the collector never relocates them and a wipe leaves no moved copy. SecretBuffer wipes the allocation it owns on `Dispose()` but cannot erase caller arrays, copied strings, OS buffers, swap or crash dumps. `ReadOnlySpan<byte>` parser views borrow caller memory, while client event/inquiry `ReadOnlyMemory<byte>` views borrow channel or inquiry storage: an escaped alias becomes invalid after its lease ends even if C# still lets the caller hold it. Dispose leases before another read and protect any intentional copies separately.

A client owns the stream passed to `FromStreamAsync` and invalidates it after uncertain I/O, cancellation, malformed framing or abandoned transactions. An unfinished inquiry closes its connection; `END`/`CAN` never replace the enclosing command's final `OK`/`ERR`. Bounded collection copies data only on explicit request. Secret collection protects decoded data in SecretBuffer, while status and comment metadata remain ordinary managed memory.

TCP loopback is not OS-authenticated. Install application authentication in `ISessionHooks<TState>.AuthenticateAsync` for services that need it; the default hooks only accept an already admitted transport. Unix listeners require a private current-user directory and verified peer UID. Listener disposal does not remove its Unix pathname: call the listener's explicit identity-checked `Cleanup()` when appropriate. Windows native GnuPG agent sockets are loopback TCP plus a binary nonce stored in the socket file. Use the resolved endpoint's `ConnectAsync` rather than connecting to its exposed port alone.

A TCP listener admits any peer that can reach its address. The default `ServerOptions` allow 128 sessions, a 120-second greeting budget and a 300-second idle budget, so unauthenticated connections that stay silent can occupy every session for minutes. For a listener reachable beyond loopback, lower `greetingTimeout`, `idleTimeout` and `maxSessions` to what the service needs, and authenticate in `AuthenticateAsync`. The library provides no transport encryption.

On Windows, a named-pipe client connects with identification-level security, so a pipe server can learn who connected but cannot act as that user. The client also refuses a pipe that is not owned by the current user, the Administrators group or the local system: a pipe name is first come, first served, and another account could otherwise create it before the intended server. On Linux and macOS, `UnixConnector.ConnectAsync` does not check who is listening; `UnixConnector.ConnectToCurrentUserAsync` asks the operating system for the server's credentials and refuses another user. `AgentLocator` accepts only a fully qualified `gpgconf` path, never a name resolved through the working directory or `PATH`.

Diagnostics and generated `ILogger` integration emit only fixed component, category, outcome and numeric counts; they do not carry payloads, remote messages, nonce, full private path or exception objects. Separately exposed technical causes may contain OS-provided text and require caller redaction. Source-generated command/OPTION methods do not authenticate clients, register themselves or send final responses.
