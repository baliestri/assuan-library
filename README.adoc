= AssuanLibrary (.NET)

AssuanLibrary is an asynchronous .NET library for applications that communicate using the Assuan protocol. It is designed around binary-safe client and server sessions, bounded protocol processing, and pluggable transports such as TCP, Unix domain sockets, Windows named pipes, and custom streams.

== Status

* [x] Canonical binary S-expressions: bounded parsing, scoped views, owned values, and encoding
* [x] Assuan protocol primitives: wire parsing/encoding, framing, secret storage, and state validation
* [x] TCP and custom byte streams with bounded asynchronous line I/O
* [x] Windows named pipes with a current-user access policy
* [x] Unix sockets: Linux verified with private directories, peer UID checks, and safe cleanup
* [ ] Unix socket validation on macOS
* [x] Discovery and connection to an existing GnuPG agent (fixture-tested; real-agent interop pending)
* [ ] Server sessions, handlers, and concurrent serving
* [ ] Client transactions, inquiries, and response collection
* [ ] Incremental source generators and optional DI/Logging integrations
* [ ] Selectable examples in one console application
* [ ] Complete public documentation, NuGet README, `llms.txt`, and `llms-full.txt`
* [ ] CI/CD and release 2.0.0

See link:docs/s-expressions.md[the S-expression guide] for usage, byte limits and buffer ownership.
See link:docs/protocol.md[the protocol guide] for Assuan wire parsing, framing and secret storage.
See link:docs/transport.md[the transport guide] for TCP, custom streams and channel ownership.
See link:docs/local-ipc.md[the local IPC guide] for Unix socket and Windows named pipe policies.
See link:docs/agent-discovery.md[the agent discovery guide] for `gpgconf`, binary paths and the Windows nonce.

[source,csharp]
----
using AssuanLibrary.SExpressions;

var value = SExpressionParser.ParseComplete("(3:foo0:)"u8);
foreach (var child in value.Children) {
  Console.WriteLine(child.AtomBytes.Length);
}

var owned = value.ToOwned();
byte[] canonical = SExpressionWriter.ToCanonical(owned);
----

Until 2.0.0 is published, reference `src/AssuanLibrary/AssuanLibrary.csproj` directly from a .NET 10 project to use the implemented functionality. The published 1.x package has a different API.

== Build and test

The solution is `AssuanLibrary.slnx` and the main library targets `net10.0`. The generator project targets `netstandard2.0` for compiler-host compatibility. Dependencies use `Directory.Packages.props`.

[source,shell]
----
dotnet restore AssuanLibrary.slnx
dotnet build AssuanLibrary.slnx -c Release
dotnet test --project tests/AssuanLibrary.Tests/AssuanLibrary.Tests.csproj -c Release
----

The solution selects the Microsoft.Testing.Platform runner in `global.json` for its xUnit v3 projects. The separate generator test project is currently empty; it will receive tests with the generator stage.
