= AssuanLibrary (.NET)

AssuanLibrary is an asynchronous .NET library for applications that communicate using the Assuan protocol. It is designed around binary-safe client and server sessions, bounded protocol processing, and pluggable transports such as TCP, Unix domain sockets, Windows named pipes, and custom streams.

== Status

* [x] Canonical binary S-expressions: bounded parsing, scoped views, owned values, and encoding
* [x] Assuan protocol primitives: wire parsing/encoding, framing, secret storage, and state validation
* [x] TCP and custom byte streams with bounded asynchronous line I/O
* [x] Windows named pipes with a current-user access policy
* [x] Unix sockets: Linux verified with private directories, peer UID checks, and safe cleanup
* [ ] Unix socket validation on macOS
* [x] Discovery and connection to an existing GnuPG agent (fixture-tested; real-agent interop pending)
* [x] Serial server sessions, typed handlers, hooks, and bounded inquiries
* [x] Bounded concurrent server acceptance and supervised shutdown
* [x] Serial client transactions, borrowed events, and bounded response collection
* [x] Interactive client inquiries and greeting callbacks
* [x] Incremental server handler registration and OPTION routing (solution analyzer reference)
* [x] Conditional DI/Logging generation and analyzer in the main local NuGet package
* [x] Selectable examples in one console application
* [x] Local public documentation, NuGet README, DocFX API reference, `llms.txt`, and `llms-full.txt` generation
* [ ] CI/CD and release 2.0.0

[source,csharp]
----
using System;
using AssuanLibrary.SExpressions;

var value = SExpressionParser.ParseComplete("(3:foo0:)"u8);
foreach (var child in value.Children) {
  Console.WriteLine(child.AtomBytes.Length);
}

var owned = value.ToOwned();
byte[] canonical = SExpressionWriter.ToCanonical(owned);
----

Until 2.0.0 is published, reference `src/AssuanLibrary/AssuanLibrary.csproj` directly from a .NET 10 project to use the implemented functionality. The published 1.x package has a different API.

== Examples and installation

Run the single console application to list available scenarios or select one without external services:

[source,shell]
----
dotnet run --project examples/AssuanLibrary.Examples -- --list
dotnet run --project examples/AssuanLibrary.Examples -- --example sexpressions
dotnet run --project examples/AssuanLibrary.Examples -- --example custom-transport
----

For a loopback TCP demonstration, run these in separate terminals with the same explicit port. Stop the server with Ctrl+C. This demonstration does not authenticate a TCP peer.

[source,shell]
----
dotnet run --project examples/AssuanLibrary.Examples -- --example tcp-server --port 9000
dotnet run --project examples/AssuanLibrary.Examples -- --example tcp-client --port 9000
----

To query an *existing* GnuPG agent, supply a trusted `gpgconf` executable. Add `--homedir <path>` deliberately; if omitted, `gpgconf` uses its configured default. The example does not start an agent or display secrets.

[source,shell]
----
dotnet run --project examples/AssuanLibrary.Examples -- --example agent-info --gpgconf <path>
----

When released, `dotnet add package AssuanLibrary --version 2.0.0` will install the runtime and analyzer in one package. Version 2.0.0 is **breaking** relative to the published 1.x API; it is not published yet. Streams, event leases and secret buffers require explicit disposal. Clients are serial per connection, and the Windows agent path must be connected through its resolved endpoint to send the nonce.

== Build and test

The solution is `AssuanLibrary.slnx` and the main library targets `net10.0`. The generator project targets `netstandard2.0` for compiler-host compatibility. Dependencies use `Directory.Packages.props`.

[source,shell]
----
dotnet restore AssuanLibrary.slnx
dotnet build AssuanLibrary.slnx -c Release
dotnet test --project tests/AssuanLibrary.Tests/AssuanLibrary.Tests.csproj -c Release
----

The solution selects the Microsoft.Testing.Platform runner in `global.json` for its xUnit v3 projects. Run generator tests separately with `dotnet test --project tests/AssuanLibrary.Generators.Tests/AssuanLibrary.Generators.Tests.csproj -c Release`.

Build the versioned public site and LLM navigation locally with the pinned DocFX tool as described in link:docs/guides/operations.md[documentation operations]. A new output version cannot replace an existing bundle; no website or package is published by this command.
